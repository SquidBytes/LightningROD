LightningROD
Demo Docs GitHub

Self-hosted charging and vehicle analytics.

Developed for the Ford F-150 Lightning and other Ford EVs.

LightningROD collects your vehicle data automatically, so you don't need to keep spreadsheets.

Try the demo Read the docs GitHub

The demo is read-only. The data is random, so values may not add up, and the service may need a moment to wake up.

Quick Start

git clone https://github.com/SquidBytes/LightningROD.git
cd LightningROD
cp .env.example .env   # set POSTGRES_PASSWORD
docker compose up -d
docker run -d \
  -p 8000:8000 \
  -v lightningrod-data:/data \
  -e DATABASE_URL=sqlite+aiosqlite:////data/lightningrod.db \
  --name lightningrod \
  ghcr.io/squidbytes/lightningrod-web:latest
Runs at http://localhost:8000. Unraid, and external databases: Installation guide

Features

  • Charging SessionsSort, filter, add, edit, and export sessions. Open one to see its cost and charge curve.
  • Cost AnalyticsWhat you paid per network, subscription savings, and comparisons against gas or other networks.
  • Charging PerformanceAC vs DC energy, charging efficiency over time, and an estimated DC charge curve.
  • Battery AnalyticsState of charge, pack temperature, charge curves, and estimated degradation.
  • DrivingTrip list with drive graphs, plus efficiency vs temperature and regen.
  • Review QueueVerify, edit, or merge the networks and locations LightningROD picks up.

Data Sources

Pick whichever fits your setup. You can use more than one.

  • Home AssistantReads live data from ha-fordpass and detects charging sessions automatically. Best if you already run Home Assistant.
  • FordConnectReads straight from Ford's API, no Home Assistant needed. Requires a Ford developer account. Only North America has been tested.
  • CSV importUpload charging sessions from a spreadsheet. Work in progress
  • Manual entryAdd or edit a session by hand from the Charging Sessions page.
What's next

EVSE-direct (Ford Charge Station Pro, OCPP) and more import formats (XLSX, network app exports). Long term, OBD readers, so the API isn't required.
