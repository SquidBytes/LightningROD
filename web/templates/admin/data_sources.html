Data Sources

Every field LightningROD ingests is declared in a source adapter's FIELD_CONTRACTS registry. This page shows the current registry and the last raw value observed for each contract. Per Phase 29 D-C1, the registry is the single source of truth for unit handling.

Column legend:
  • Declared Unit — the source_unit literal on the contract. A HA-conv badge means ha-fordpass itself converts this field via localize_distance / localize_temperature / units.pressure() — so the effective per-event source unit is derived from ha_config.unit_system.
  • Effective Unit — the unit actually used on the most recent event. May differ from the declared unit when HA-conversion or read-time UoM resolution fired.
  • Resolution Method — how the adapter picked the effective unit: declared, ha_unit_system_converted, read_time_uom, or declared_fallback.
